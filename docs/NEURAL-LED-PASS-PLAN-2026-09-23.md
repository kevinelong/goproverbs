# Pass-agreement treatment: validation and fresh screens

User authorized this rule, tests, saved-failure replay, a small endgame set and
fresh paired screens. Preserve every earlier run. No source changes during
inference, no commits/default promotion. One serial model job at a time.

## Rule and controls

For evaluated variants, after obtaining a timely legal root policy move, if the
opponent's immediately preceding move is pass and that root move is also pass,
return pass without candidate comparison. Record exact resulting TT score and
pass_agreement=true, completed_rounds=0, fallback=false. Raw policy is unchanged.
All other decisions retain the existing winrate-first comparison and full-history
clone optimization. Late/cancelled agreement processing is a recorded root
fallback, not a timely agreement. This is a changed decision rule, not proof
that ending play is optimal. Policy itself can recommend a premature pass.

Deterministic controls cover both colors, wins/losses/draws, all evaluated roles,
one missing agreement condition, exact scoring, state preservation and deadline
overrun. Keep all previous regression tests, including full-history superko.

seed23092026 corner procedure, excluding all prior opening files modulo board
symmetry. The next20 are neural versus policy; the other20 combined versus

No tuning, win-based early stopping, retries of failed games or adjudicated wins.

Existing operational gates remain: stop on malformed/missing root, illegal move,
